## Project Description

Ma-eul Ilgam is a bilingual prototype that helps rural farmers turn requests into clear work opportunity cards. A farmer describes a task, reviews and edits the draft, and approves it for a young person to inspect alongside their skills and availability. The demonstration uses fictional data and does not publish a listing or arrange employment. We hope to explore whether clearer local opportunities can help people discover work in rural communities; we have not measured any effect on retention or employment.

## Describe your use of Meta products

The prototype integrates Muse Spark 1.3 via Meta Model API to extract task, location, timing and compensation from a written request. It integrates Muse Voice Transcribe for supported WAV uploads. The farmer can edit the draft and unknown fields remain visible. [Before submitting, confirm these paths still work and describe any limitations observed.]

## Why are Meta's models important?

A conversational input can reduce the effort of turning an informal request into structured information. Speech transcription can let a farmer start with a recording, while language extraction prepares a draft for the farmer to review. The user remains responsible for the information and the decision to pursue work.
