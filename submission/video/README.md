# Demo video

`maeul-ilgam-demo.mp4` is a 2:24 narrated first cut for the hackathon. It uses three fictional scenes generated with Meta Muse Image and real screenshots captured from the app during a live Muse Spark request. Narration uses a system voice. Generated scenes are clearly labeled and must not be presented as actual interviews or outcomes.

The interface sequence consists of still captures. The event guide expects a working demo and judges assess live operation. Before submission, add a continuous recording of the real workflow, review the whole video including audio, and provide a judge-accessible video link. Real user research and a live deployment are not yet verified.
