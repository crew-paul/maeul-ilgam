# 범위 변경 기록

사용자 요청에 따라 실제 서비스 v2의 과도한 기능을 해커톤 v3으로 축소했다.

유지: 실제 데이터 저장·소유권·간단 인증·Meta 음성/대화형 등록·게시/탐색·관심 전달·전화/이메일 공유·영/한·배포·제출.

제외: 관리자·농가 검증·프로필/온보딩·채팅·알림·선정/수락·계약·작업/완료 관리·지급 확인·분쟁·분석·복잡한 검색.

농가의 주 사용자가 고령자라는 점을 최우선 UX 기준으로 반영했다. 연락은 전화/이메일 선택, 지급은 당사자 직접 처리로 확정했다.

이번 변경은 명세 수정이다. 코드에 아직 존재하지 않는 기능을 삭제했다고 주장하지 않는다. 과거 전체 서비스의 미구현 작업 문서는 Git 기록에 남기고 현재 활성 목록에서 제거한다.
