# 해커톤 완료 기준

| ID | 필수 검증 |
|---|---|
| A01 | 고령 농가용 텍스트 기본·항목 전체 펼침·선택 음성·최종 수정이 동작 |
| A02 | Meta가 없는 날짜/보수를 만들지 않고 추가 답변을 반영하며 직접 수정한 내용은 재확인 |
| A03 | 로그인 없는 게시/읽기, 작성자 쿠키로 소유권 보호, 타인 초안/변경 차단 |
| A04 | 농가가 게시한 일감이 별도 기기의 목록·상세에서 보이고 서버 실행 중 새로고침 후 유지 |
| A05 | 필수 정보 부족 시 해당 입력을 표시하고 마감 후 신규 관심 차단 |
| A06 | 청년이 전화 또는 이메일을 선택·공유 동의해 관심 전달, 해당 농가만 연락처 열람 |
| A07 | 중복 요청 방지와 관심 철회 후 연락처 숨김, 전화/mailto 행동 확인 |
| A08 | 영어/한국어 전환·390px 화면·키보드·큰 글자에서 전체 흐름 완료 |
| A09 | 마이크 거부·모델 오류·인증 만료·저장 충돌에서 복구, 비밀/연락처 노출 없음 |
| A10 | 배포 링크에서 전체 실제 동작, 공개 코드, 3분 이내 영상과 제출 설명이 일치 |

모델 호출 성공만으로 게시·관심 전달이 구현됐다고 판단하지 않는다. 고령 사용자 사용성 검증과 기기 녹음 검증은 수행 전 미검증으로 남긴다. 관련 테스트·타입/빌드와 핵심 E2E만 실행하고 실제 결과를 기록한다.
