# 현재 구현과 목표의 차이

2026-11-02 코드 점검 기준. 이 표는 기능을 구현했다고 주장하는 계획표가 아니라 관찰한 상태다.

| 영역 | 현재 코드 | v2 출시까지 필요한 것 |
|---|---|---|
| 계정·권한 | 없음 | 이메일 인증·세션·역할·소유권·운영자 권한 |
| 데이터 | React 메모리 상태 | PostgreSQL·스키마·마이그레이션·임시저장·재접속 복구 |
| 농가 | 가상 예시 | 실제 프로필·확인·권한·담당자 |
| 일감 | 한 요청→초안→화면 승인 | 완전한 조건·공개 검토·게시·목록·검색·상세·revision |
| Meta | 실제 텍스트 추출/추가 설명 호출 및 WAV 전사 | 구조화 출력·근거·충돌 처리·비동기 실행·한도·개인정보 처리 |
| 녹음 | 브라우저 녹음·변환 코드 | 실제 장치·권한·취소·용량·오류 검증 |
| 참여자 | 같은 세션의 조건 입력 화면 | 독립 계정·탐색·신청·철회·프로필 |
| 연결 | 없음 | 대화·제안·수락·정원·알림 |
| 작업·보수 | 없음 | 조건 확정·작업·완료·취소·직접 지급 확인·이견 |
| 운영 | 없음 | 농가/게시 검토·신고·정지·감사·지원 |
| 언어·UI | 단일 화면의 영/한 문구 | 모든 여정·서버 오류·이메일·정책·운영 화면 현지화 |
| 배포·기반 | 로컬 실행 | 스테이징·공개 배포·DB/저장소/이메일·백업·모니터링 |
| 제출 | 문안 초안·정지 이미지 영상 초안 | 실제 동작 녹화·전체 재생 검수·호스팅·실제 범위에 맞춘 설명 |

결론: 현재 서비스는 출시되지 않았고 출시 가능 판정을 받지 않았다. 초기 시제품 검사를 전체 서비스 검증으로 확대 해석하지 않는다.
