# 구현과 검증 현황

2026-11-02 최신 변경: 텍스트 기본·전체 입력 펼침·음성 선택·비로그인 등록/읽기. 이전 음성 우선·게시 전 인증은 대체했다. 작성자는 비밀 쿠키로 관리하며 신청의 인증/동의는 유지한다. [변경 검증](../features/text-first-guest-mvp/validation.md).

이전 검증 기록: 현재 코드는 7개 URL의 일감 게시·탐색·관심 전달 흐름이다.

- 구현: 영어/한국어, 음성 우선 등록 UI와 한 질문씩 보완, Meta 텍스트 추출/전사, 최종 수정, 게시 전 인증, 저장/게시/수정/마감, 지역 검색·상세, 관심 연락처 선택/동의/전달/철회, 본인 목록.
- 저장: 서버 메모리 PGlite와 작성 중 초안 Map. 새로고침 동안 유지되지만 재시작 시 계정·세션·일감·관심·초안 모두 초기화. 영구 DB는 사용자 요청으로 제외.
- 통과: server/app.test.js 관련 통합 테스트 9개, TypeScript·Vite 빌드. 소유권·초안 복구·게시 조건·중복·철회·마감·충돌·인증 재사용·교차 출처 쓰기 검사.
- 브라우저 관찰: 실제 Meta 가상 영어 요청 → 최종 확인 → 로컬 개발 인증 → 게시 → 별도 청년 계정 이메일 관심 전달 → 새로고침 후 내 관심 유지. 한국어 내 관심과 390px 표시 확인.
- 미검증: 실제 SMS/이메일 공급자 발송, 실제 마이크·현장 방언, 고령자 사용성, 전 기기 여정, 공개 배포. 개발 인증은 화면에 코드를 표시하는 로컬 테스트이며 실제 발송이 아니다.
- 기존 영상은 정지 이미지와 실제 화면 캡처를 편집한 초안이며 최종 제품 시연으로 갱신해야 한다.

운영 콘솔·채팅·선발·작업/정산 관리는 제외 범위다. 해커톤 구현과 대중 대상 서비스 운영 준비를 같은 뜻으로 사용하지 않는다.

실제 로컬 서버(3010)를 종료하고 재시작한 뒤 Chrome에서 로그인 세션과 등록 일감이 초기화되고 빈 목록으로 표시되는 것을 확인했다. 가상 테스트 데이터는 재시작으로 제거했다.

추가 검증: [생성자·신청자 E2E와 예시 데이터](../features/demo-data-e2e/validation.md). 독립 호스트 Chrome 여정 완료, 연락처 갱신 시 신청자 수 동기화 수정. SEED_DEMO_DATA=1은 재시작 때 예시 10개만 새로 생성한다.
