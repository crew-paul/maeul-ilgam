# 해커톤 기술 구성 v3

React·TypeScript·Vite와 Node·Express를 유지한다. 계정·일감·관심은 서버 프로세스 메모리에 저장한다. PGlite로 SQL 제약과 트랜잭션을 사용하지만 파일·원격 DB에는 저장하지 않는다. 서버 재시작 시 모든 데이터와 세션이 초기화된다. 데이터 계약은 런타임 검증하고 데이터 변경은 소유권을 서버에서 검사한다. 기술을 추가하기보다 핵심 여정에 필요한 구조를 만든다.

전화 OTP 인증을 우선 제공하고 이메일 인증을 대안으로 제공한다. 인증 전송 공급자 어댑터와 서버 세션을 사용한다. 공급자는 아직 미정이며 실제 인증 없이 데모 역할 선택을 실제 로그인으로 표현하지 않는다. 게시 전 인증에서 작성 내용이 유실되지 않게 브라우저 복구와 서버 임시 초안 소유권 이관을 설계한다.

Meta Voice Transcribe와 Muse Spark는 서버에서만 호출한다. 브라우저 녹음은 지원 WAV로 변환한다. 키·개인 연락처는 프런트 번들이나 AI 입력에 넣지 않는다. AI 장애에도 직접 작성 경로는 동작한다.

배포는 HTTPS 단일 출처, API와 메모리 DB, 인증 전송 공급자로 구성한다. 내부 채팅·outbox·운영자 콘솔·결제·지급 원장·비공개 증빙 저장소·분석 플랫폼은 추가하지 않는다. 음성은 처리 뒤 삭제하고 영구 업로드 기능을 만들지 않는다.

작업마다 계획·요구사항·검증 결과를 작성하고 통과 시 커밋한다. 기본 검사는 직접 관련 테스트와 타입/빌드, 최종에는 핵심 여정 E2E다. 이전 시제품 결과를 새 기능 통과로 재사용하지 않는다.
