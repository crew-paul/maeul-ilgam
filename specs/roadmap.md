# 해커톤 구현 작업 v3

기능별 plan·requirements·validation을 먼저 작성하고, 직접 검사 통과 후 코드와 결과를 커밋한다. 이 표는 목표 작업이며 구현 완료 표시가 아니다.

| 작업 | 범위 | 선행 | 인수 기준 |
|---|---|---|---|
| H01 service-foundation | DB·세션·전화/이메일 인증·초안 복구·소유권 | 없음 | A03,A04,A09 |
| H02 service-publishing | 텍스트 기본·항목 전체 펼침·음성 선택·비로그인 게시·큰 확인·저장/게시/수정/마감 | H01 | A01,A02,A05 |
| H03 service-discovery | 7개 화면의 목록/상세/내 일감/내 관심, 전화/이메일 관심 전달 | H01,H02 | A04,A06,A07 |
| H04 service-submission | 배포·영/한/기기 검증·실제 시연·영상·제출 자료 | H01–H03 | A08–A10 |

목표는 7개 URL, 고령 농가 등록과 청년 연락 시작의 실제 완주다. 서버 실행 중 데이터 공유와 권한은 실제 동작으로 검증한다. 서버 재시작 시 초기화하는 메모리 저장을 사용한다. 미정 공급자는 호스팅/인증 전송뿐이며 일반 서비스 운영 프로세스는 이번 작업에 추가하지 않는다.

최신 변경: [텍스트 기본·비로그인 MVP](features/text-first-guest-mvp/plan.md). 기존 음성 우선과 게시 전 인증 목표를 대체한다.
