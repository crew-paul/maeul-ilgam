# 고령 농가를 위한 등록 UX

## 최우선 원칙

농가 사용자는 고령자다. 문자를 빠르게 입력하고 복잡한 메뉴를 이해한다고 가정하지 않는다. 등록 완료까지 ‘다음에 무엇을 해야 하는지’ 매 순간 명확해야 한다. AI 기능이나 시스템 설정을 이해할 필요가 없어야 한다.

## 첫 화면과 질문

- 큰 ‘말로 등록하기’ 버튼이 주 행동, ‘글로 적기’는 같은 결과로 가는 보조 행동이다.
- 한 화면에 한 가지 질문과 주 행동 하나를 둔다. 긴 폼·작은 카드 여러 개·데스크톱 사이드바에 핵심 행동을 숨기지 않는다.
- ‘초안·전사·API·스키마·설정됨·작업 공간’ 대신 ‘말한 내용·고치기·확인하기·등록하기’를 쓴다.
- 녹음 중에는 ‘듣고 있어요’와 ‘다 말했어요’를 크게 보여준다. 녹음은 항상 사용자가 시작하고 멈춘다.
- 날짜는 ‘오늘/내일/날짜 고르기’, 인원은 숫자 선택, 보수는 큰 숫자 입력과 ‘시간당/하루/전체’ 선택으로 보완한다. 실제 날짜도 함께 표시해 상대적 날짜 오해를 막는다.
- 뒤로 가거나 인증을 해도 작성 내용이 유지된다. 실수로 나갈 때 복구할 수 있다.

## 읽기와 조작

농가 등록 본문 목표 20px, 보조 글 최소 16px, 주 버튼 높이 56px 이상을 기본으로 검증한다. 충분한 줄 간격·명도 대비, 버튼 사이 간격, 분명한 문장과 눌림 상태를 제공한다. 아이콘만 있는 핵심 버튼과 작은 드롭다운을 사용하지 않는다.

영어가 기본이지만 상단에 ‘한국어’를 직접 선택할 수 있게 표시한다. 선택을 기억하고 등록 도중 바꿔도 내용이 보존된다. 언어별 긴 문장·큰 글자·200% 확대·390px 화면을 검증한다.

## 최종 확인

‘이 내용으로 등록할까요?’ 아래에 실제 값과 ‘바꾸기’를 함께 보여준다. 보수·날짜는 특히 크게 읽힌다. 선택한 경우 기기 내장 읽기 기능으로 확인 내용을 들을 수 있게 하되 이를 Meta 음성 합성이라고 주장하지 않는다. 확인을 거쳐야 게시되고 AI가 대신 게시하지 않는다.

## 장식과 상태

그림·마스코트·광고 문구보다 현재 질문과 사용자의 실제 답이 우선이다. 녹음·처리·실패 상태는 소리나 색만으로 전달하지 않는다. 실패 시 ‘다시 해보기’와 ‘직접 적기’를 제공하고 입력을 잃지 않는다. 파일 형식·모델 이름·비용·키 설정은 이용자가 선택할 필요가 있을 때만 도움말에 둔다.

## 검증

고령 사용자에게 설명 없이 등록을 시작해 최종 확인까지 진행하도록 사용성 검증한다. 도움이 필요했던 지점·오입력·완료 여부를 기록한다. 실제 고령자 검증 전에는 ‘고령자에게 검증된 UX’라고 표현하지 않는다.
