# Meta AI·언어·접근성

## 제품에서 사용하는 모델

- Muse Voice Transcribe: 녹음/파일을 전사한다. 선택 언어를 힌트로 제공한다. 녹음 전 마이크 권한과 전송 안내, 녹음 중 상태·중지·재녹음을 제공한다.
- Muse Spark: 요청의 구조화, 누락 조건 질문, 추가 설명 반영, 원문과 연결된 요약을 담당한다.
- 모델 ID와 한도는 서버 설정에서 관리한다. 모든 제품 AI 추론은 Meta로 제한한다. 이름을 보여주는 것만으로 검증된 품질을 주장하지 않는다.

## 출력 계약

입력 원문, 사용자 확인 필드, 추가 답변을 구분한다. `fields`, `missingFields`, `questions`, `evidence`, `warnings`를 JSON으로 반환하고 서버가 스키마를 검증한다. 금액·기간·장소의 출처가 없으면 값을 넣지 않는다. 사용자가 직접 확정한 값을 갱신하려면 충돌 항목을 보여주고 다시 확인받는다.

AI 초안 생성은 저장·게시·신청·선정·직접 지급 확인을 수행하지 않는다. AI 응답은 신뢰할 수 없는 입력으로 처리하고 HTML을 실행하지 않는다. 자동 번역은 보조 표기로만 사용하며 원문의 보수·일정은 함께 볼 수 있게 한다.

## 실패와 비용

타임아웃·용량 초과·비정상 JSON·429·권한 오류를 구분하고 현지화된 오류 코드로 안내한다. 요청 ID를 사용해 생성 진행과 재시도를 추적한다. 키가 없으면 실제 서비스에서 AI 버튼은 사용 불가와 직접 작성 경로를 보여준다. 무단 수동 결과를 Meta 응답처럼 대체하지 않는다.

작성은 AI 장애 중에도 수동으로 완료할 수 있다. 녹음은 길이와 파일 크기 제한, 지원 형식 검사·변환, 취소 시 스트림 해제를 제공한다. 원본 음성은 기본적으로 영구 보관하지 않는다. 운영 환경의 분당/일별 사용자·IP 제한과 프로젝트 비용 상한을 설정한다.

## 데이터

이름·연락처·계좌·정확한 주소 등 업무 작성에 필요 없는 데이터는 Meta 전송에서 제외한다. 전사 전 원본 음성에 개인 정보가 포함될 수 있음을 안내한다. 표준 데이터 처리 모드를 기본으로 하며 학습 사용에 동의하는 모드를 자동으로 켜지 않는다. 보관·삭제 정책은 operations 명세를 따른다.

## 언어

기본 `en`, 추가 `ko`. URL/계정 선호에 따라 저장하고 변경해도 입력·상태를 잃지 않는다. UI·오류·알림·이메일·운영자 화면·정책·접근성 이름까지 번역 키로 관리한다. 서버는 번역된 문장 대신 오류 코드를 반환한다. 사용자 작성 원문과 언어는 보존한다. 시각은 저장 시 UTC, 표시 시 `Asia/Seoul`과 현지화된 날짜·통화 형식으로 보여준다.

## 접근성

키보드만으로 전 여정 완료, 필드와 오류 연결, 초점 이동·복귀, 대비, 녹음 상태의 스크린리더 알림, 축소 동작, 200% 확대를 확인한다. 음성을 사용할 수 없는 사람도 텍스트로 동일 기능을 완료한다. 핵심 정보와 행동은 색에만 의존하지 않는다.
