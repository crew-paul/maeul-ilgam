# Meta AI와 언어

## 고령 농가의 입력

Muse Voice Transcribe로 음성을 글로 바꾸고 Muse Spark로 일감 항목과 빠진 조건을 찾는다. 말하기→전사문 확인→누락 질문 하나씩→최종 확인 순서다. 한꺼번에 여러 질문을 쏟아내지 않는다. UI는 ‘말로 등록하기’, ‘다 말했어요’, ‘바꾸기’처럼 이용자가 이해하는 말을 쓴다.

Meta 출력은 fields·missingFields·questions·evidence·warnings로 검증한다. 입력하지 않은 보수·날짜는 미정으로 두고, 사용자 확정 값과 충돌하면 덮어쓰지 않고 다시 묻는다. 녹음 인식이 틀리면 원문을 고치거나 직접 작성한다. AI가 게시·관심 전달·선정·연락·송금을 수행하지 않는다.

질문을 들려주거나 최종 내용을 읽어줄 때 기기의 읽기 기능을 보조적으로 사용할 수 있다. Meta가 제공하지 않는 음성 합성 기능을 Meta 모델의 기능으로 표현하지 않는다. 제품 AI 추론은 Meta만 사용한다.

## 장애와 보호

키·연락처·계좌·정확한 주소는 모델 입력에서 제외한다. 음성 공유 안내와 사용자가 시작하는 녹음, 크기/시간 제한·취소·스트림 해제를 제공한다. 모델 타임아웃·인식 실패·한도·형식 오류에도 답변과 초안은 유지한다. AI가 없어도 직접 작성할 수 있으며 실패를 성공으로 대체하지 않는다.

## 영/한

기본 en, 추가 ko. 상단의 한국어 선택은 큰 글자로 쉽게 찾고 마지막 선택을 기억한다. 질문·오류·확인·인증·연락처 동의도 번역한다. 언어를 바꿔도 녹음 후 내용과 입력·단계가 사라지지 않는다. 사용자 원문은 보존하고 날짜는 실제 날짜·시간대, 보수는 금액·단위·통화를 명확히 표시한다.

## 검증

영/한과 실제 고령 사용자의 말투로 누락 질문·수정·최종 확인을 점검한다. 사투리/마이크 검증을 실행하기 전 성능을 주장하지 않는다. 키보드·화면 읽기·큰 글자·대비·텍스트 대안을 제공한다.
