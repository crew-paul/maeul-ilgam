# 상태와 연락 전달

## 일감

`draft → published → closed`. 임시저장·게시·마감은 서로 다른 상태다. 게시에는 필수 조건이 필요하며 로그인은 요구하지 않는다. 비로그인 소유자는 비밀 브라우저 쿠키로 구분한다. 공개된 글은 소유자만 수정/마감할 수 있다. 수정 시 갱신 시각을 표시하고 관심을 보낸 청년이 현재 조건을 다시 볼 수 있게 한다. 거래 확정 기록이나 계약 버전은 만들지 않는다.

## 신청 (내부 API: interests)

`active → withdrawn`. 같은 청년이 같은 일감에 중복 관심을 보낼 수 없다. 새로고침·재시도로 중복 저장되지 않는다. 모집 마감 후 신규 관심을 막고 기존 관심과 연락 동의 기록은 유지한다. 철회하면 농가 화면에서 연락처를 숨긴다. 이미 본 사람이 기억한 연락처나 외부 연락을 회수할 수 있다고 표현하지 않는다.

## 전화 또는 이메일

청년은 이름·짧은 메모·연락 수단(phone/email)·연락처와 농가 공유 동의를 제공한다. 전화번호는 국가코드와 표시 형식을 지원하고 이메일은 유효 형식을 검사한다. 선택한 연락처만 해당 일감 소유자에게 보여준다. 공개 목록·상세·로그·Meta 프롬프트에는 보내지 않는다.

농가 화면의 ‘전화하기’는 tel 링크, ‘이메일 보내기’는 mailto 링크다. 실제 통화·이메일 전송·채용 성사를 완료했다고 서비스가 임의로 기록하지 않는다. 내부 채팅·대량 연락·자동 이메일은 없다.

지급은 직접 처리하며 서비스의 상태에 지급/수령/분쟁 단계를 추가하지 않는다.
