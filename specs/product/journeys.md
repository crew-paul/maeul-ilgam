# 사용자·화면·핵심 여정

## 정보 구조

## 농가 여정

1. 이메일 인증 후 농가 프로필을 작성하고 확인을 요청한다. 확인 전에도 일감 초안은 작성할 수 있다.
2. 필요한 일을 말하거나 적는다. 전사문을 먼저 수정할 수 있고, Meta가 만든 항목에는 근거 발화와 미확인 조건을 표시한다.
3. 빠진 항목에 답하거나 직접 입력한다. 초안은 서버에 저장되고 다른 화면으로 이동해도 복구된다.
4. 게시 전 공개 정보와 필수 조건, 개인정보 노출을 확인한다. 운영 검토가 필요하면 대기 상태와 사유를 안내한다.
5. 게시 후 문의와 신청을 본다. 농가가 직접 참여를 제안하고 참여자가 수락하면 인원이 확정된다.
6. 확정 조건으로 작업을 진행하고 완료·지급을 각각 기록한다. 상대방이 동의하지 않으면 상태를 자동으로 완료하지 않는다.

## 참여자 여정

1. 로그인 없이 지역 일감을 탐색한다. 정확한 개인 연락처·상세 집 주소는 공개 목록에 노출하지 않는다.
2. 일감 상세에서 업무·예상 시간·보수·지급일·교통·농가 확인 여부를 확인한다.
3. 인증 후 자기소개·관련 경험·가능 여부를 직접 작성해 신청한다. AI 점수나 자동 탈락은 없다.
4. 농가의 제안을 받고 조건 버전을 읽고 동의한다. 거절·철회도 가능하다.
5. 대화에서 집결 장소 등을 확인한다. 작업 후 완료·보수 수령 또는 이견을 기록한다.

## 공통 UX 규칙

- 사용자별 작업함과 데이터 소유권을 구분한다. 화면에서 역할을 바꾸는 것만으로 타인의 작업함에 접근하지 않는다.
- 저장·게시·신청·확정은 각기 다른 행동과 상태다. 확인 전 게시된 것처럼 보이지 않는다.
- 빈 화면에는 실제 다음 행동, 실패 화면에는 보존된 입력과 재시도, 오래된 화면에는 갱신 시각을 표시한다.
- 모바일에서도 목록→상세→신청과 녹음→초안→검토가 완료돼야 한다. 확인 버튼은 44px 이상의 터치 영역을 갖는다.
- 모든 버튼은 실제 동작·이동 경로를 가진다. 안내용 그림을 동작하는 기능처럼 표시하지 않는다.
