# 7개 화면과 사용자 여정

| 번호 | URL | 화면·행동 |
|---|---|---|
| 1 | `/` | 실제 일감 목록과 지역 검색. 큰 ‘일감 등록’과 ‘일감 찾기’ 행동 |
| 2 | `/jobs/:id` | 일감 상세와 전화/이메일로 관심 전달 양식 |
| 3 | `/sign-in` | 전화 또는 이메일 인증. 게시/관심 전달 후 돌아갈 위치와 작성 내용 유지 |
| 4 | `/farmer/jobs` | 내 일감 목록, 수정·마감, 해당 일감 관심자와 연락처 펼쳐보기 |
| 5 | `/farmer/jobs/new` | 말하기→조건 확인→최종 확인→게시. 로그인은 게시 직전 |
| 6 | `/farmer/jobs/:id/edit` | 같은 등록 흐름을 사용한 수정·재확인 |
| 7 | `/my/interests` | 전달한 관심 내역, 현재 일감 상태, 철회 |

등록의 단계와 상세 안의 관심 전달은 별도 페이지로 세지 않는다. 작성/수정은 하나의 UI를 공유한다. 별도 홈·설정·프로필·운영자·대화·알림 페이지는 없다.

## 고령 농가 등록

1. 로그인 없이 ‘말로 등록하기’를 누른다. 마이크 거부 시 ‘글로 적기’로 이어간다.
2. 필요한 일을 말하고 ‘다 말했어요’를 누른다. 녹음 내용은 다시 듣거나 고칠 수 있다.
3. 빠진 조건을 한 가지씩 묻는다. 예: ‘일하실 곳이 어디인가요?’ → ‘언제 도움이 필요하세요?’ → ‘보수는 얼마인가요?’
4. 이미 말한 내용을 반복 질문하지 않는다. 답을 해석하지 못하면 쉬운 예와 직접 입력을 제공한다.
5. 마지막 화면에서 업무·지역·날짜/시간·보수·인원을 큰 글자로 보여준다. 각 항목 옆에 ‘바꾸기’가 있다.
6. ‘이대로 등록하기’를 누르면 필요한 인증을 진행하고 돌아온다. 완료 화면에 게시된 일감과 ‘내 일감 보기’를 제공한다.
7. 청년이 관심을 보내면 내 일감에서 이름·메모·동의한 전화/이메일을 보고 ‘전화하기’ 또는 ‘이메일 보내기’를 선택한다.

## 청년

목록→지역 검색→상세→관심 전달. 이름·한 줄 메모와 전화/이메일 중 하나를 입력하고 해당 농가에 연락처를 공유하는 데 동의한다. 등록 완료는 ‘관심을 전달했어요’로 안내하며 일자리 확정이라고 표현하지 않는다. 내 관심에서 철회할 수 있다.
