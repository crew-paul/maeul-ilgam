# 해커톤 필수 범위

| ID | 기능 | 완료 조건 |
|---|---|---|
| H01 | 브라우저 작성자·소유권 | 등록/읽기 비로그인, 작성자 쿠키로 관리, 타인 변경 차단 |
| H02 | 텍스트로 등록 | 모든 항목을 펼친 텍스트 폼, 음성·Meta 추출 선택 |
| H03 | 확인·게시 | 업무·지역·날짜/시간·보수·모집 인원을 쉬운 말로 확인하고 서버에 게시 |
| H04 | 탐색 | 실제 게시 일감 목록·상세, 지역 검색, 모집/마감 표시 |
| H05 | 연락 시작 | 로그인한 청년이 전화 또는 이메일을 선택·공유 동의해 관심 전달, 농가만 열람 |
| H06 | 내 일감·내 신청 | 농가는 작성/게시/수정/마감/관심자 확인, 청년은 관심 내역/철회 |
| H07 | 완성도·제출 | 영/한·모바일·데이터 저장·보안·배포·실제 시연과 영상 |

## 제외

관리자 콘솔, 농가 인증 심사, 별도 프로필/온보딩, 내부 채팅, 알림함, 마케팅 메일, 참여자 평가/선발, 제안/수락/정원 예약, 계약, 작업 시작/완료 관리, 지급/수령/이견 기록, 결제·수수료·에스크로, 별점, 분석 대시보드, 복잡한 다중 필터를 만들지 않는다.

연락 이후의 일정·보수 합의와 직접 지급은 당사자가 처리한다. 서비스 안에 지급 완료 버튼을 두지 않는다. 기본 개인정보 안내·지원 연락처는 화면 하단/도움말 영역에 제공하며 별도 복잡한 운영 화면은 만들지 않는다.

## 게시 조건

무슨 일인지, 시군/읍면 수준의 지역, 실제 날짜와 시간/예상 시간, 보수 금액·단위·통화, 모집 인원이 필요하다. 초안은 미정으로 저장할 수 있으나 필수 조건이 없으면 해당 입력을 표시하고 게시를 막는다. 공개 연락처·계좌·정확한 집 주소는 본문에 넣지 않도록 안내한다. AI가 보수·날짜를 추정해 채우지 않는다.

## 완료

농가와 청년의 별도 브라우저에서 게시→발견→관심 전달→농가 연락처 확인이 배포 환경에서 실제로 작동한다. 서버가 실행 중이면 새로고침·재로그인 후 데이터가 유지되고, 서버를 다시 시작하면 초기화된다. 3분 영상은 검증된 동작 범위만 설명한다.
