# 출시 범위와 완료 정의

## 출시 필수 기능

| ID | 기능 | 완료 조건 |
|---|---|---|
| P01 | 계정과 세션 | 이메일 일회용 링크 로그인, 로그아웃·만료·계정 정지, 서버 권한 검사 |
| P02 | 프로필·농가 확인 | 참여자 프로필과 농가 프로필 저장, 운영자 확인을 통과한 농가만 게시 |
| P03 | 일감 작성 | 직접 작성, Meta 음성 전사·초안·추가 질문, 임시 저장·복구, 모든 필드 수정 |
| P04 | 검토와 게시 | 필수 조건 검사, 게시 동의·개인정보 확인, 초기 제한 공개의 모든 일감 운영 검토, 수정·마감 |
| P05 | 탐색 | 실제 저장된 게시 일감 목록·상세·지역/업무/기간/보수 필터와 정렬, 종료 상태 표시 |
| P06 | 문의·신청 | 계정별 신청, 중복 방지, 철회, 일감별 문의와 메시지, 이메일·서비스 내 알림 |
| P07 | 참여 확정 | 농가 수동 제안과 참여자 확인, 모집 인원 초과 방지, 조건 버전 고정 |
| P08 | 작업·직접 지급 | 시작·완료 확인, 지급 예정일·농가 지급 신고·참여자 수령 확인·이견 기록 |
| P09 | 운영 | 농가 확인·게시 검토·신고·취소·계정 정지·감사 기록, 운영자 문의 |
| P10 | 실서비스 기반 | 영구 데이터, 권한 격리, 백업·복구, 비밀키 보호, 배포·모니터링·영/한 전체 흐름 |

## 첫 출시에서 지원할 업무

상품 사진·판매 소개 보조, 포장·선별 등 농가가 제공할 범위와 안전 안내를 설명할 수 있는 업무부터 시작한다. 기계 조작, 농약 취급 등 별도 자격·고위험 작업은 초기 모집 허용 목록에서 제외한다. 운영자는 게시 내용을 검토하고 업무 허용 목록을 관리한다.

## 업무 조건

일감은 제목·설명·업무 종류·시군/읍면·시작/종료 시각·시간대·휴게 및 예상 소요·인원·보수 금액/단위/통화·지급 예정일/방식·교통 및 준비물·담당 농가를 담는다. 미정 항목을 허용하는 작성 초안과 모집 가능한 게시물의 조건은 구별한다. 보수 미정·일정 미정은 저장은 가능하지만 공개 모집은 불가하다.

## 직접 지급

서비스는 자금을 보관하거나 송금하지 않는다. 지급 조건은 확정 기록에 남고 지급 처리 여부는 양측 보고로 표시한다. 법적 효력의 계약을 자동 생성한다거나 지급을 보증한다고 표현하지 않는다. 실제 운영에 사용할 모집·업무관계·보수 정책은 출시 전 운영 주체가 검토·승인한다.

## 출시 후 확장

플랫폼 결제·다지역 확장·공개 별점·외국인 계절근로 행정·자동화된 지원자 평가·입찰·급여 계산·보험·분쟁 중재 판정은 이번 출시 범위에 포함하지 않는다. 첫 운영 후 근거와 정책을 확보해 별도 명세로 검토한다.

## 완료의 정의

P01–P10의 필수 인수 기준이 실제 배포 환경에서 통과하고, 운영 주체와 지원 경로가 준비돼야 제한 공개 가능하다. AI 데모와 영상 완성은 서비스 출시 완료를 대신하지 않는다. 공개 출시는 별도 출시 게이트를 따른다.
