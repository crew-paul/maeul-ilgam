# Mission v3

고령 농가가 말로 필요한 도움을 설명하면 청년이 이해할 수 있는 실제 유료 일감으로 게시하고, 지역 청년이 발견해 직접 연락을 시작하게 한다.

농가에게는 양식 작성 부담을 줄이고, 청년에게는 어디서·언제·무엇을·얼마에 하는지 명확한 정보를 제공한다. AI는 작성 보조를 맡고 사람의 선정·판단을 대신하지 않는다.

성공한 한 건: 농가가 말한다 → 부족한 조건에 답한다 → 결과를 듣거나 읽고 확인한다 → 일감을 게시한다 → 다른 기기에서 청년이 발견한다 → 전화/이메일 공유에 동의해 관심을 전달한다 → 농가가 연락처를 보고 직접 연락한다.

연락 시작이 해커톤 서비스의 끝이다. 실제 고용·작업·지급·인구 유지 효과는 검증 전 주장하지 않는다.
