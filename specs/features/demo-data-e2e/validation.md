## 실제 브라우저 E2E

생성자 `creator.localhost:3010`, 신청자 `applicant.localhost:3010`으로 쿠키를 분리했다.

| 역할 | 관찰 결과 |
|---|---|
| 생성자 | 로그인 없이 텍스트 등록·최종 확인·게시 성공. 신청자 이름과 선택 이메일 확인. 이후 보수 50,000→55,000 수정, 모집 마감 성공 |
| 신청자 | 비로그인 목록·지역 검색·상세 성공. 개발 이메일 인증 후 원래 상세 복귀. 공유 동의 후 신청, 내 신청에서 취소. 전화 연락처로 재신청·취소도 성공 |
| 상호 반영 | 생성자에게 이메일/mailto와 전화/tel 링크 표시. 취소 후 연락처 제거. 신청자 상세에 수정한 보수 반영. 마감 후 양식 사라지고 Closed 표시 |

발견/수정: 연락처 새로고침 뒤 신청자 수가 낡게 남았다. 최신 연락처 목록과 인원수를 함께 갱신하도록 수정하고, 실제 브라우저에서 0→1→0 변경을 확인했다.

가상 이름·example.com 이메일·테스트 번호만 사용했다. 실제 이메일/SMS 발송·전화·고용/지급은 수행하지 않았다. E2E용 일감은 마지막에 마감하여 공개 목록에는 예시 10개만 남겼다. 전사/마이크와 배포 환경 검증은 이번 테스트 범위가 아니다.
