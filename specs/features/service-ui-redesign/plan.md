# Service UI redesign

## Scope
Improve the shared navigation, job discovery and job registration, and align the remaining screens with the same accessible visual system. Keep routes, API calls, data, authentication and payment behavior unchanged. English is the default and Korean is available throughout.

## Design direction
A practical village noticeboard: quiet neutral surfaces, a restrained green action color, clear rules and readable type. Show real job information early. Group every registration field under visible headings; keep text input first and voice optional. Avoid decorative cards and oversized hero space.

## Validation
Run the production build and directly related role-journey tests. Inspect desktop and mobile pages in a real browser when the browser connection is available, including posting and applying, keyboard focus and overflow. Record any unverified work honestly.
