# H01 검증 결과

2026-11-02: 사용자 요청에 따라 파일 경로 없는 PGlite와 서버 Map에만 저장한다. 관련 통합 테스트 9개와 타입 검사·빌드 통과.

- 빈 메모리 저장소, 새로고침/인증 전후 임시 초안 유지, 별도 브라우저 초안 접근 차단.
- 본인 일감만 수정, 타인 초안 비공개, 연락처 소유권, 중복 관심·철회, 마감, version 충돌.
- 잘못된/재사용 인증번호 거부, 교차 출처 쓰기 차단.
- Chrome에서 로컬 개발 인증 후 농가 게시 → 별도 청년 계정 관심 전달 → 새로고침 후 내 관심 유지 관찰.

SMS/이메일 실제 발송은 공급자 키가 없어 미검증. 개발 코드는 테스트임을 명시하고 production에서 금지한다. 서버 재시작 후 데이터 유지 요구는 사용자 요청으로 제외하며, 모든 계정·세션·초안·일감·관심이 초기화된다.

실제 로컬 서버(3010)를 종료하고 재시작한 뒤 Chrome에서 로그인 세션과 등록 일감이 초기화되고 빈 목록으로 표시되는 것을 확인했다. 가상 테스트 데이터는 재시작으로 제거했다.
