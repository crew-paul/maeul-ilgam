# 요구사항

- R1: 텍스트 폼이 기본이다. 모든 등록 필드는 접힘 없이 보이며 별도 AI/음성 사용 없이 게시 가능하다.
- R2: 음성 사용은 명시적으로 선택한다. 선택해도 기존 텍스트 입력을 잃지 않는다.
- R3: 비로그인 방문자가 게시·목록·상세를 사용할 수 있다. 게시 후 같은 브라우저에서 내 일감 관리 가능하다.
- R4: 타 브라우저는 소유자 초안·수정·마감·신청 연락처에 접근할 수 없다. 공개 상세 조회는 가능하다.
- R5: 로그인 없이 읽을 수 있다는 최신 지시를 적용한다. 신청 연락처 공유는 별도 동의/기존 인증을 유지한다.
- R6: 데이터는 서버 메모리이며 재시작 시 초기화한다. 작성자 쿠키를 지우면 익명 작성물 관리 권한을 복구할 수 없음을 안내한다.
