# 텍스트 기본·비로그인 MVP 계획

2026-11-02 최신 사용자 지시가 기존 음성 우선·게시 전 인증·상세 로그인 지시를 대체한다.

1. 등록은 기본 텍스트 폼으로 업무·장소·날짜·시간·보수·인원을 모두 펼쳐 표시한다. 음성은 선택 버튼으로만 시작한다.
2. 비로그인 등록·상세 조회를 허용한다. 비밀 브라우저 쿠키로 작성자를 구분하고 본인 일감 수정·마감·신청 연락처 조회 권한을 유지한다.
3. 목록 행동은 View details / 자세히 보기, 신청은 별도 행동이다. 읽기만으로 신청·연락처 공유가 발생하지 않는다.
4. 관련 API 통합 검사·타입/빌드·브라우저 등록/조회만 검증하고 커밋한다.
