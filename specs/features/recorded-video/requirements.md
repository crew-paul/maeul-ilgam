# 요구사항

- 한국어 내레이션, 영어 자막. 영어는 발화의 의미를 유지한다.
- 실제 입력·모델 응답·게시·신청·연락처 표시를 연속 녹화한다. 대기 축약은 편집이며 생성 UI나 스틸 조합으로 바꾸지 않는다.
- Meta 사용을 보여줄 때 실제 서버 호출과 결과를 사용한다. 가상 데이터·로컬 인증·메모리 저장 제한을 명시한다.
- 인물 스톡은 예시 장면으로 표시한다. 실제 사용자 인터뷰·고용 성과로 주장하지 않는다. 출처/라이선스를 기록한다.
- 전체 길이·프레임·오디오·자막 및 주요 시각 구간을 검증한다. 공개 업로드는 별도이며 이번에는 로컬 파일을 생성한다.
