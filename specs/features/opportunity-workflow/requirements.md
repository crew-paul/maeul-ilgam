# Opportunity workflow requirements

- R1: Default to English and switch to Korean without resetting user data.
- R2: Accept typed requests and audio recordings. Meta Voice transcribes audio only when the API is configured; show failures without pretending they succeeded.
- R3: Derive a draft with task, location, timing and compensation. Missing fields remain empty and are visibly marked, never invented.
- R4: A farmer can edit every field and must approve the draft before it is displayed to a young person.
- R5: A young person can enter skills and availability and compare them with the approved card. Show exact provided information and unknowns; do not score, rank, or screen people.
- R6: Expose whether the result is simulated or generated by Meta. Do not create an employment contract, publish a listing or claim a connection occurred.
- R7: UI provides a fictional sample, error/loading states, keyboard labels and mobile layout.
- R8: All app features and UI chrome support English and Korean; generated content can remain in the original language.
