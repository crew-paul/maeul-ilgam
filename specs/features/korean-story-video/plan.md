# 한국인 등장인물·무내레이션 개정

기존 서양인 스톡과 한국어 내레이션을 대체한다. 한국인 고령 농가가 농작물을 팔고 싶으나 온라인 판매 방법을 몰라 고민하고, 시골에서 느긋하게 시간을 보내던 청년이 촬영 일감을 발견하는 가상 이야기로 바꾼다. 영어 자막만 제공하며 인물 대사나 해설 음성은 넣지 않는다. 앱 화면은 기존 실제 녹화를 유지한다.

## 예산 결정

사용자: “아니 150 크레딧만 사용해”. 이미 지급받은 Meta Model API $150 크레딧의 남은 범위만 허용한다. 추가 $150 지출 승인이 아니다. 별도 vidIQ 크레딧, 외부 유료 생성, 유료 스톡 구매, 자동 결제 또는 충전을 사용하지 않는다. Meta 잔액을 확인하지 못한 상태에서 남은 금액을 추정하지 않는다.

## 현재 실행 범위

계정 모델 목록에는 동영상 생성 모델이 없다. 추가 비용 없이 기존 실제 앱 녹화만으로 무내레이션·영어 자막 편집본을 생성한다. 서양인 스톡은 새 편집본에서 제외한다. 한국인 농가/청년 인물 동영상은 미확보 상태로 명시하며, 실제 동영상 대신 정지 이미지를 이어 붙여 완료했다고 표현하지 않는다. 현재 편집본은 완성된 인물 스토리 영상이 아니다.
