# 한국인 사진 이야기 + 실제 앱 시연

## 최신 사용자 결정

“인물 장면 사진을 여러장 붙이고 뒤쪽만 시연 영상으로 만들자. 여러장 붙여서 영상이 멈춰있지 않게. 영어 설명 자막이 계속 이어지도록.” 이에 따라 사진 사용을 금지했던 이전 계획은 대체한다.

## 범위

1. Meta Muse Image로 가상의 한국인 노인·청년 사진 8장 생성. 인물·옷차림 참조로 일관성 유지.
2. 농가 수확→포장→온라인 판매 고민→시골에서 한가로운 청년→지역 촬영 일감 발견→만남→상품 촬영 순서.
3. 사진마다 부드러운 확대·축소·이동, 사진 사이 0.4초 디졸브. 약 32.4초.
4. 뒤쪽은 기존 실제 앱 녹화 137초. 생성 UI를 쓰지 않는다.
5. 총 약 169.4초, 내레이션/음성 없음. 시작부터 끝까지 영어 설명 자막을 이어서 표시.
6. 새 영상·자막·재현 스크립트·검증 결과 생성 후 관련 파일 커밋. 앱 기능은 변경하지 않음.

## 예산

이미 지급받은 Meta Model API $150 크레딧의 남은 범위만 허용. 외부 유료 생성·별도 크레딧·유료 스톡·충전 금지. 새 사진 8장, 공개 단가 $0.01/장 기준 $0.08. 자동 재생성/재시도 없음. API 요청 검증 실패는 생성 성공과 구분하고 실제 계정 잔액은 추정하지 않음.

## 검증 범위

8개 인물 사진과 주요 합성 프레임 직접 확인. 영어 자막 전체 시간 연속성·3분 이내·오디오 없음·전체 디코드·사진 구간 프레임 변화 검사. 앱 코드 변경이 없어 앱 테스트는 재실행하지 않음.

## 시연 속도 개정

사용자: “뒷편에 시연화면을 좀 더 속도감있게”. 앞 32.4초 인물 사진 구간을 그대로 재사용하고, 앱 시연을 137초에서 80초로 단축한다. 모델 응답 대기·인증 대기·연락처 확인 대기를 잘라내고 나머지 동작을 빠르게 재생한다. 영어 자막을 짧게 다듬어 전체 112.4초에 연속 표시한다. 새 이미지/API 호출 없음. 수정된 시연의 디코드·자막·주요 동작과 앞부분 동일성을 검증한다.

## 시연 중간 프레임 깨짐 수정

사용자 보고: 시연 중간에 이상한 프레임이 끼며 깨짐. 원본 5개 영상의 전체 495개 저장 프레임을 검사하여 절반 크기 브라우저 캔버스가 좌상단에 찍힌 불량 21개를 확인했다. 검토한 원본 프레임 번호·시각·해시를 기록한다. 원본을 보존하고 불량 프레임을 제외한 뒤 원래 시각을 유지하며 30fps로 정규화한다. 시연 컷을 정제된 실제 녹화로 다시 렌더한다. 최종 시연 2,400프레임 전체에서 같은 불량 모양이 남지 않는지 검사하고, 문제 전후의 연속 프레임을 직접 검토한다. 길이·자막·앞 32.4초 인물 장면은 유지하고 외부/API 호출은 하지 않는다.
