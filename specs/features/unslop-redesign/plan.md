# Design task plan

Audit the existing screen against unslop's signs. Direction: a practical, welcoming rural work desk; plain language; a sample job note as the visual anchor; a thin green edge identifies farmer-approved work. Revise copy, typography, spacing, color and layout without changing feature behavior. Validate with the production build and a focused browser walkthrough.
