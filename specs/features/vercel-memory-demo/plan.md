# Vercel memory-only demo

Use a Vercel Node function for the existing Express API and Vite's built assets for the frontend. Preserve in-memory PGlite and the anonymous draft map, Meta integration, guest posting, and real-provider-only authentication in production. Seed the ten fictional demo jobs per instance. Each function instance has independent, disposable memory; this deployment is a hackathon demonstration and cannot promise shared or persistent state. Validate build, API behavior and, after deployment, live routing and provider availability.
