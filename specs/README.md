# 마을일감 해커톤 명세 v3

2026-11-02 · 현재 구현 기준 · v2의 과도한 출시 범위를 이 문서로 대체한다.

## 핵심

농가의 주 사용자는 고령자다. 텍스트로 필요한 일과 조건을 입력하고, 농가가 확인해 로그인 없이 게시한다. 음성 입력과 Meta 조건 추출은 선택 기능이다. 청년은 다른 기기에서 저장된 일감을 발견하고 전화번호 또는 이메일을 공유해 관심을 전달한다. 양측은 직접 연락하고 보수도 직접 지급한다.

고령 농가가 복잡한 구인 양식을 작성하지 않아도 실제 지역 일감이 만들어지는 흐름을 해커톤의 중심으로 삼는다.

## 확정 사항

- 영어 기본, 한국어 전 기능 지원. 한국어 선택을 항상 쉽게 찾을 수 있어야 한다.
- 모든 제품 AI는 Meta. 키는 서버에만 보관한다.
- 텍스트 기본, 모든 등록 항목을 펼쳐 표시, 음성은 선택, 큰 글자와 큰 버튼, 확인 후 게시.
- 서버 메모리 저장·소유권 보호·별도 사용자 탐색과 관심 전달은 필수다.
- 연락처는 전화 또는 이메일 선택. 관심 전달 시 해당 농가에만 공유한다.
- 내부 채팅·운영자 콘솔·농가 인증·참여자 선발·작업/정산 관리·지급 확인은 제외한다.
- 작업별 명세→구현→관련 검증→커밋. 목표와 실제 구현 상태를 구분한다.

등록·목록·상세는 로그인 없이 사용한다. 익명 작성물은 비밀 브라우저 쿠키로 관리하고 타인 변경은 차단한다. 최신 변경 명세: [텍스트 기본·비로그인 MVP](features/text-first-guest-mvp/plan.md).
