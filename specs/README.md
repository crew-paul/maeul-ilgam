# 마을일감 서비스 명세 v2

작성: 2026-11-02 · 상태: 구현 기준 초안 · 실제 서비스 출시 기준

## 제품 정의

마을일감은 농가가 필요한 일을 구체적인 유료 일감으로 게시하고, 지역에서 일하고 싶은 사람이 탐색·문의·신청하며, 농가와 참여자가 업무·보수·일정을 확인하고 작업을 마치는 지역 일감 연결 서비스다. AI는 농가의 작성과 정보 이해를 돕는다. 채용·선정·보수 변경은 사람이 결정한다.

## 확정된 결정

- 첫 사용 화면과 기본 언어는 영어. 모든 출시 기능은 한국어로도 제공한다.
- 제품의 모든 AI 추론은 Meta 모델을 사용한다. 모델 키는 서버 전용이다.
- 개인 참가자의 실제 작동 서비스로 개발한다. 농가와 참여자는 서로 다른 기기·계정으로 사용한다.
- 보수는 당사자 간 직접 지급한다. 플랫폼 결제·수수료·에스크로는 초기 출시 범위에 없다.
- 기능 단위로 명세 → 구현 → 검증 → 커밋한다. 명세에는 목표, 검증 기록에는 실제 결과를 쓴다.
- 디자인은 실제 업무와 정보를 중심으로 한다. 기존 taste-skill과 unslop 지침을 적용하되 시연용 한 화면에 제품 구조를 가두지 않는다.

## 출시를 위한 작업 가정

한 시·군에서 운영자가 확인한 농가부터 제한 공개한다. 신청자는 18세 이상으로 제한하는 제품 정책을 둔다. 운영 지역·운영 주체·이메일 전송 사업자는 아직 결정되지 않았다. 이는 출시 전 확정 항목이며 구현 완료로 취급하지 않는다.

## 이전 문서

기존 `opportunity-workflow`, `record-and-clarify`, `unslop-redesign`, `submission-package`, `demo-video`는 초기 시제품의 범위와 작업 기록이다. 해당 폴더의 기존 요구사항은 v2 출시 기준이 아니다. 과거 검증 기록은 당시 관찰 결과만 의미하며 현재 전체 서비스의 통과 증거가 아니다.

새 활성 작업은 `specs/features/service-*` 아래에서 관리한다. 계정·데이터·게시·신청·연락·운영·배포를 빠뜨린 시제품은 출시 완료로 표시하지 않는다.
