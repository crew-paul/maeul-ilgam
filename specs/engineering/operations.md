# 데모 배포와 기본 보호

서버 키는 배포 비밀 설정에 둔다. .env는 Git에 포함하지 않는다. HTTPS, 보안 세션 쿠키, CSRF/origin 검사, 인증·AI·관심 전달 요청 제한, 업로드 형식·크기·길이 검사를 적용한다. 개인 연락처·토큰·음성 원문은 로그에서 제외한다.

사용자 요청에 따라 데이터는 서버 메모리에만 둔다. 서버 시작 시 빈 스키마를 만들고 재시작하면 초기화되는 것을 검증한다. 서버는 한 인스턴스로 실행하며 자동 재시작·재배포 시 데이터가 사라진다. 가상 시연 자료는 명시한다. 큰 운영 대시보드·정산·신고 큐는 만들지 않는다.

한정된 해커톤 검증에서 실제 참여자가 쓰는 경우 개인정보 안내와 전화/이메일 공유 동의를 제공한다. 일반 대중 대상 서비스 확대는 별도 운영 검토 대상이며 이번 해커톤 완료 조건과 구별한다.

필요한 외부 설정: 호스팅·인증 메시지 공급자. 확정되지 않은 공급자와 작동하지 않는 인증은 완료로 표시하지 않는다.
